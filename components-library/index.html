LiquidChrome

WebGL animated liquid metal background yang respond kepada mouse. Effect iridescent morphing using ogl + custom shader.

  • Mouse-interactive distortion
  • Configurable colors, speed, amplitude
  • No external libs (just ogl via CDN)
  • Perfect untuk hero section

MagicBento

Responsive grid layout dengan spotlight tracking, border glow, 3D tilt pada hover, dan click ripple effects.

  • Mouse-tracked global spotlight
  • Border glow on hover
  • 3D perspective tilt
  • Click ripple effect
  • 1/2/4 column responsive
View demo →

GlassSurface

Liquid glass effect dengan SVG chromatic aberration. Refraction effect yang beautiful untuk modals & floating panels.

  • SVG feDisplacementMap shader
  • 3-channel chromatic aberration
  • Auto-resize via ResizeObserver
  • Configurable blur & distortion
