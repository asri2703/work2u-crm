# Work2U Client Portal

_Dokumen rujukan untuk akses luar client, dokumen, invoice, approval, dan self-service._

## Objective

Sediakan portal client yang:

- mudah digunakan
- mengurangkan back-and-forth
- profesional untuk sharing dokumen
- terpisah daripada internal workspace

## Scope

Dokumen ini fokus pada:

- invite flow
- verify / connect flow
- client home screen
- documents
- invoice and payment
- approval action
- activity history

## Portal Features

- view invoice
- download receipt / document
- approve quotation
- check service status
- upload file
- see next action
- view conversation summary

## Portal Flow

1. client terima invite link
2. client verify identity
3. client masuk ke portal
4. client lihat status dan action yang perlu dibuat
5. client complete approval / payment / upload
6. system update timeline internal

## Portal Principles

- simple
- read-only by default
- action-based, bukan full workspace access
- secure external access

## Non-goals

- akses penuh ke internal CRM
- editing bebas oleh client
- campur data client dengan data staff

## Decision Status

- portal dipisahkan daripada internal workspace: yes
- portal digunakan untuk invoice, docs, status, approval: yes
